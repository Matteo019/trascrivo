# Termini d'uso — Trascrizioni

Ultimo aggiornamento: [data]

## 1. Il servizio

Trascrizioni è un servizio privato, gestito da [nome], che trascrive in testo file audio caricati dagli
utenti. È gratuito, fornito "così com'è", senza garanzie di disponibilità, continuità o accuratezza.
[Valutare con il consulente limitazioni di responsabilità ammesse.]

## 2. Accesso

- Si accede **solo su invito** dell'amministratore. Non è prevista la registrazione libera.
- L'account è personale: non condividere la password. Se pensi che qualcuno l'abbia scoperta, cambiala
  subito dal tuo profilo e avvisa l'amministratore.
- L'amministratore può sospendere o chiudere un account in qualsiasi momento, in particolare in caso di
  uso non conforme a questi termini.

## 3. Uso consentito

Puoi caricare solo registrazioni che hai il diritto di registrare e trascrivere. In particolare:

- **informa le persone registrate** (docenti, colleghi, relatori) e, dove serve, chiedi il loro consenso;
- rispetta le regole del luogo in cui registri (scuola, università, azienda) e i diritti d'autore sui
  contenuti delle lezioni o degli eventi;
- non caricare contenuti illeciti né dati particolari (salute, opinioni politiche, ecc.) di altre persone
  senza una base giuridica valida.

Sei responsabile di come usi le trascrizioni ottenute.

## 4. Limiti

Ogni utente ha limiti di dimensione e durata per file e di numero di file al giorno, indicati nella pagina.
Le trascrizioni avvengono **una alla volta**: nei momenti di maggiore uso i file restano in coda. Le
richieste dell'amministratore possono avere la precedenza.

## 5. Conservazione

L'audio viene cancellato appena la trascrizione è terminata. Il testo resta disponibile per [7] giorni,
poi viene cancellato automaticamente: **scaricalo per tempo**. Puoi eliminarlo prima con il pulsante
"Elimina". Il servizio non è un archivio e non conserva copie di sicurezza delle trascrizioni
[verificare la politica di backup].

## 6. Qualità delle trascrizioni

La trascrizione è automatica e **può contenere errori**, omissioni o parole sbagliate, soprattutto con
audio di scarsa qualità, più persone che parlano insieme o termini tecnici. Rileggi sempre il testo prima
di usarlo.

## 7. Servizi esterni

Se copi una trascrizione in un servizio esterno (per esempio un'intelligenza artificiale online), i dati
escono dal controllo di questo servizio. Non condividere dati sensibili. L'uso è a tuo carico.
